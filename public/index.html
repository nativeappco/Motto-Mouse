Product lookup

Search by box number (e.g. B7018), PO number or pattern number. Separate up to 20 with commas, or paste a column from a spreadsheet, to look them up together.

Enter a box number and Motto Mouse will fetch everything Airtable knows about it.

Settings

Choose which Airtable fields the product lookup shows. Fields are loaded live from the BOX #S table.

Shopify mapping

Choose which Shopify product, variant or metafield each Airtable field from the BOX #S table is written to, and how existing Shopify data is treated.

Merge
Add to what's in Shopify, e.g. extra tags. Text is appended. Nothing is added twice.
Replace
Overwrite the Shopify value.
New
Only fill the field if it's empty in Shopify.
